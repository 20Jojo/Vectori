# Vectori

A Next.js storefront for Vectori photobooks and magazines.

This is a local demo: cart, accounts and orders are stored in the browser, and no payments or emails are sent. See `docs/research/vectori/page-brief.md` for the route map and known gaps.

## Run it

Requires Node.js 24 or newer.

```bash
npm install
npm run dev
```

Then open http://localhost:3000.

## Checks

```bash
npm run check
```
